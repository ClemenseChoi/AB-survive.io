# Survive 2D

Surviv.io 스타일의 2D 탑다운 배틀로얄 게임입니다. **서버가 모든 판정을 하는 온라인 멀티플레이 구조**로 만들었어요.

- 서버: Node.js + WebSocket(`ws`). 이동, 총알 판정, 피해, 아이템, 자기장, AI 봇을 전부 서버가 계산합니다.
- 클라이언트: 브라우저 HTML5 Canvas. 입력만 서버로 보내고, 서버가 보내 준 상태를 그립니다.
- 같은 서버가 게임 페이지(`public/`)도 같이 제공하기 때문에, **배포는 서비스 1개면 끝**입니다.

---

## 1. 내 컴퓨터에서 실행하기

[Node.js](https://nodejs.org) 18 이상이 필요합니다 (LTS 버전 설치 권장).

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 을 엽니다. 창을 여러 개 띄우면 여러 명이 접속한 것처럼 테스트할 수 있어요.

같은 와이파이에 있는 친구는 `http://내컴퓨터IP:3000` 으로 접속할 수 있습니다 (Windows: `ipconfig`, Mac: `ifconfig` 로 IP 확인. 방화벽이 막으면 허용해 주세요).

### 환경 변수 (선택)

| 이름 | 기본값 | 설명 |
|---|---|---|
| `PORT` | 3000 | 서버 포트 (호스팅 서비스가 자동으로 지정) |
| `BOTS` | 24 | 한 판에 들어가는 AI 봇 수 |
| `MAX_PER_ROOM` | 30 | 방 하나에 들어갈 수 있는 사람 수. 넘으면 새 방이 생깁니다 |
| `DEBUG_LOADOUT` | (없음) | `1` 로 두면 시작부터 총·방어구를 줍니다 (테스트용) |

Mac/Linux 예시: `BOTS=10 DEBUG_LOADOUT=1 npm start`
Windows PowerShell 예시: `$env:BOTS=10; npm start`

## 2. 인터넷에 공개하기 (Render 무료 배포)

### ① GitHub에 올리기
1. [github.com](https://github.com) 에서 새 저장소(New repository)를 만듭니다. 예: `survive-2d`
2. 이 폴더에서 아래 명령을 실행합니다 (`node_modules`는 `.gitignore` 때문에 올라가지 않아요).
   ```bash
   git init
   git add .
   git commit -m "first commit"
   git branch -M main
   git remote add origin https://github.com/내아이디/survive-2d.git
   git push -u origin main
   ```
   명령어가 어렵다면 GitHub 웹에서 "uploading an existing file"로 `node_modules`를 뺀 파일들을 끌어다 놓아도 됩니다.

### ② Render에서 서비스 만들기
1. [render.com](https://render.com) 에 GitHub 계정으로 가입합니다.
2. **New → Web Service** 를 누르고 방금 만든 저장소를 선택합니다.
3. 설정:
   - **Runtime**: Node
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
   - **Instance Type**: Free
   - (선택) Health Check Path: `/health`
4. **Create Web Service** 를 누르면 몇 분 뒤 `https://survive-2d-xxxx.onrender.com` 같은 주소가 생깁니다. 이 주소를 친구에게 보내면 끝이에요.

코드를 고쳐서 GitHub에 다시 push하면 Render가 자동으로 다시 배포합니다.

### 무료 요금제에서 알아둘 점
- 무료 서버는 **15분 동안 아무도 접속하지 않으면 잠들고**, 다음 접속 때 깨어나느라 첫 로딩이 수십 초 걸릴 수 있습니다.
- 게임 중에는 클라이언트가 계속 메시지를 보내기 때문에 잠들지 않습니다.
- 서버가 재시작되면 진행 중인 판은 끊깁니다 (저장되는 데이터는 없어서 문제는 없어요).
- 항상 켜 두고 싶으면 유료 요금제를 쓰거나 Railway, Fly.io 같은 다른 서비스를 쓰면 됩니다. 이 프로젝트는 `npm start` 하나로 실행되기 때문에 Node.js를 지원하는 곳이면 어디든 그대로 올라갑니다.

> 요금제와 무료 조건은 자주 바뀌니까 배포할 때 각 서비스의 안내를 확인하세요.

## 3. 조작법

| 키 | 동작 |
|---|---|
| W A S D / 방향키 | 이동 |
| 마우스 | 조준 · 클릭으로 사격 (MP5·AK-47은 누르고 있으면 연사) |
| F | 줍기 (총이 2자루 있으면 들고 있는 총과 교체) |
| R | 장전 |
| 1 / 2 / 3, 마우스 휠 | 무기 교체 (3번은 주먹) |
| Q | 이전 무기 |
| 7 / 8 / 9 | 붕대 / 구급상자 / 에너지 음료 사용 (HUD 버튼 클릭도 가능) |
| M | 소리 켜기/끄기 |
| Space | 관전 중 다음 플레이어 보기 |

탄약, 회복템, 더 좋은 방어구, 스코프는 밟기만 하면 자동으로 줍습니다. 빈 슬롯이 있으면 총도 자동으로 줍습니다.

## 4. 게임 내용

- **무기**: 주먹, M9(권총), MP5(기관단총), M870(샷건, 9발 산탄), AK-47(소총), Mosin(저격총)
- **탄약**: 9mm / 12게이지 / 7.62mm
- **회복**: 붕대(+15), 구급상자(100까지 회복), 에너지 음료(부스트: 천천히 회복하고 이동 속도 증가). 사용 중에는 느려지고, 쏘면 취소됩니다.
- **방어구**: 헬멧 Lv.1~3, 방탄복 Lv.1~3 (받는 피해 감소)
- **스코프**: 2x / 4x / 8x (시야가 넓어짐)
- **맵**: 건물(들어가면 지붕이 사라짐), 나무, 덤불(몸을 숨길 수 있음), 바위, 상자(부수면 아이템), 드럼통(부수면 폭발)
- **자기장**: 6단계로 줄어들고, 밖에 있으면 단계마다 피해가 커집니다. 흰 점선이 다음 안전지대입니다.
- **매치 흐름**: 판이 시작되고 40초 안에 들어오면 바로 참가하고, 그 뒤에 들어오면 관전하다 다음 판에 참가합니다. 최후의 1명이 남거나 사람이 모두 탈락하면 7초 뒤 새 판이 시작됩니다.

## 5. 구조

```
server/
  index.js    HTTP(정적 파일) + WebSocket 서버, 방(Room) 배정
  game.js     게임 한 판의 모든 로직 (틱 루프, 사격, 피해, 아이템, 자기장, 전송)
  bot.js      AI 봇 (파밍, 교전, 회복, 자기장 회피)
  mapgen.js   맵 랜덤 생성
public/
  index.html  메뉴/화면 UI
  client.js   입력, 예측 이동, 보간, 렌더링, HUD
  shared.js   서버·클라이언트 공통 규칙 (무기 수치, 이동, 충돌)
```

### 네트워크 방식
1. 클라이언트는 1초에 30번 **입력만** 보냅니다 (이동 키, 조준 각도, 사격 여부, 입력 번호).
2. 서버는 1초에 30번 게임을 계산하고, 각 플레이어에게 **화면 근처에 있는 것만** 골라 보냅니다.
3. **내 캐릭터**는 클라이언트가 먼저 움직여 보여 주고(예측), 서버 결과가 오면 아직 확인 안 된 입력을 다시 적용해 맞춥니다(보정). 그래서 핑이 있어도 조작이 바로 반응합니다.
4. **다른 플레이어**는 100ms 전 상태 두 개 사이를 부드럽게 이어서 그립니다(보간).
5. WebSocket 압축(permessage-deflate)을 켜서 한 사람당 전송량이 대략 초당 5KB 정도입니다.

### 무기 밸런스 바꾸기
`public/shared.js` 의 `WEAPONS` 에서 피해량(`dmg`), 연사 간격(`cd`), 탄퍼짐(`spread`), 사거리(`range`), 탄창(`mag`), 장전 시간(`reload`)을 바꾸면 됩니다. 서버와 클라이언트가 같은 파일을 쓰기 때문에 한 곳만 고치면 돼요.
